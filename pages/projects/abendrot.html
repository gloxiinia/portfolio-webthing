Abendrot

2021 · Python · Text-Based Adventure

A text-based adventure game demo made for a solo Algorithm and Programming project. Inspired by visual novel and choices matter video games.

My first ever programming project, it taught me a lot about navigating and using Python.

It allowed me to experiment using Python libraries like adding ASCII art and my own music, but also to practice my creative writing skills for the setting and characters.

This was first time I made a game instead of just imagining making one in my head, so I think this definitely was a milestone that made me realize I can *actually* make one.
